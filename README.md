This is a sample web project for penniless lovers😂
If your love's birthday is coming up and you don't have a low-cost idea to wish her a happy birthday, this idea is for developers or even ordinary people.
In this way, you can paste this html code and transfer this file with the necessary links to the execution service or anything like that to give you a link, QR code or the like and give it to your love to run and be surprised😉
If you have a hosting or server to run this project like all regular websites, how much better

*Note: Name your favorite photo photo.jpg, your favorite music music.mp3, and the sound of the audience cheering must be cheer.mp3

اگر تولد عشقت رسیده و ایده کم هزینه ای رو نداری که تولدش رو بهش تبریک بگی این ایده خوراک توسعه دهنده ها یا حتی افراد عادی هست
به این صورت که این کد html رو جاگذاری کنید و این فایل رو همراه متعلاقات لازم، به سرویس اجرا کننده یا هرچیزی مثل این منتقل کنید تا لینک، کیو آر کد یا امثال این رو بهتون بده و اون رو به عشقتون بدید تا اجرا کنه و سورپرایز بشه😉
اگر هم هاست یا سروری دارید که این پروژه رو مثل همه وبسایت های معمول،‌راه اندازی کنید که چه بهتر
